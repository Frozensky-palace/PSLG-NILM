## 1. 动机与消融逻辑

B4（CVAE 生成基元 + 经验路径拼接）validation 判负。进度报告 §8.4 归因
"天花板在基元模糊性（CVAE 经 MSE 训练天然平滑），而非拼接方式"——但该归因
**未被检验**：B5 系列共用 B4 的 CVAE 生成池（`compose_b5_cycles.py` 从
`--primitives-dir`＝B4 生成产物切片，代码可溯源），只换了组合器。2×2 里
"真实基元 × 组合器"一格是空的，B4R 补这一格：

| 基元来源 \ 组合器 | 经验路径 + 直接拼接 | HSMM + 边界处理 |
|---|---|---|
| CVAE 生成 | B4：15.39（s17）/ 19.43±3.74（3 seeds） | B5/B5-EP/B5-PC：44.5 / 30.6 / 15.96 |
| **真实状态段** | **B4R（本消融）** | （范围外，视 B4R 结果定） |

## 2. 干预定义（组合器不动，只换波形来源）

- `PrimitiveComposer` 加 `primitive_source={"model","donor"}`（默认 model，
  行为零变化）；donor 模式跳过 `_decode_primitive`，段波形 = 已选中的真实
  donor 本体（原始 watts，不乘 power_scale、不 clip）。
- 其余全部不动：路径模型、`MAX_PATH_STATES=12`、donor 选取的 rng 调用序列、
  段长（=donor 长）、拼接（`np.concatenate`，boundary="none"）。
- **等价性断言（可检验）**：同 seed 下 B4R 与 B4 的每条记录 `state_path` 与
  `target_samples` 逐条相同（rng 消耗序列一致，`_decode_primitive` 不消耗
  numpy rng）→ B4R 与 B4 的唯一差别是段波形内容。
- 新增记录字段填充：`donor_state_block_id` / `donor_cycle_id`（schema 已有，
  B3-T 有先例；B4R 填真实值，纯溯源，不影响行为）。

  登记条目）。机制可以是"复制 v1 后增量写臂"或"全量重建后仅取 B4R 臂合入

## 4. 质量门与记忆化口径（先声明）

- `evaluate_synthetic_quality` 照跑（impossible_peak FAIL 不可豁免）。
  duration/energy WARN 的人工接受**必须在下游 sbatch 提交前**记录：接受人、
  指标、数值、理由，写入执行日志。
- `audit_generation_memorization` 照跑、门槛不放宽（exact=0，
  replication_rate ≤ 0.01）。**口径说明**：B4R 段级与真实数据相似是定义
  属性（donor 直取）；该审计是整周期形状距离粒度。
- **单状态周期的逐位复刻风险（预声明，数字已从冻结产物提取）**：真实库
  493 周期中 47 条为单块周期，**全部属 state 1**（state 1 共 566 块）；
  B4 s17 归档 246 条记录的路径长度分布为 {1:19, 3:33, 4:164, 5:7, 6:4,
  7:19}，19 条单状态记录**全部为 state 0**（state 0 无独块 donor）→
  **本次 s17 运行的期望逐位整周期复刻数 = 0**。若层 2 升种子（s42/s73）
  出现单状态 state-1 记录，其期望复刻数 = 该类记录数 × 47/566（≈8.3%）。
  **处理规则**：审计 exact_duplicate > 0 时逐条溯源——被标记周期为单状态
  记录、且其 donor 恰为该真实周期的唯一块 ⇒ **定义性复刻**（donor 直取的
  设计属性），计数披露、不判 FAIL；任何其他形式的 exact duplicate（多状态
  记录零距离、无完整溯源对应的零距离）⇒ **真 FAIL**：如实记录、停下讨论，
  不得换 seed 重跑。replication_rate 同口径双报（原始 / 剔除定义性复刻）。
- **不重跑条款（扩展）**：任何在看到门结果或下游指标之后的再生成——换
  seed、换 count、改参数、改代码——都要求先写新协议版本 + 书面理由；
  无未经记录的重试。

## 5. 判读规则（预注册，先于下游作业提交）

锚点：B4 s17 = 15.387；B4 三种子 = 19.43±3.74（15.387/22.761/20.143）；
B2@r0.5 = 11.84±1.61；B2@r2.0 平台 = 10.38±0.08；预注册对照线 =
优于 B2@r2.0（10.38/F1 0.789）。

**噪声边际 = 1.5W**（批次 8.2 下游种子 sd 量级，B2@r0.5 臂 ±1.61）。
任何"落入某档"的判定都要求统计量距档边界 ≥ 1.5W，否则该档结论带
"阈值噪声带内"限定或按下一层处理。

### 层 1：s17 初筛（x = B4R s17 val MAE，W）

| x 落点 | 初筛方向 | 后续动作 |
|---|---|---|
| x ≤ 12.1（= 13.6 − 1.5） | 生成器模糊为主因（信号） | 升种子进层 2 确认 |
| x ≥ 16.5（= 15.0 + 1.5） | 组合路径天花板（信号） | 升种子进层 2 确认 |
| 12.1 < x < 16.5 | 灰区 | 升种子进层 2 |

初筛只决定能否**提前报告方向**；终判统计量一律是层 2 的三种子均值。
注：13.6 这个初筛中点混合了 s17 锚（15.39）与三种子均值锚（11.84），
故只作初筛用，不进入终判口径。

### 层 2：三种子终判（预注册的升级统计量）

升 s42/s73（与 B4 的作业 4174/4175 同 seed 配对），x̄ = mean(s17, s42, s73)：

| x̄ 落点 | 终判 | 后续动作 |
|---|---|---|
| x̄ ≤ 15.64 | **生成器模糊为主因**（15.64 = B4 三种子 19.43 与 B2@r0.5 11.84 的中点） | 值得训 B4-WGAN / B4-扩散基元 |
| x̄ ≥ 19.03 | **组合路径是天花板**（= B4 三种子均值 − 0.4W，与 B4 不可区分） | 不再训任何基元生成器；E 路线彻底关账 |
| 15.64 < x̄ < 19.03 | **混合归因** | 按 x̄ 在区间内的位置给两因素贡献的定性权重（近下沿偏生成器、近上沿偏组合），如实报告 B4R 相对 B4/B2 的降幅，不做二选一结论 |

层 2 同样适用 1.5W 边际：|x̄ − 档边界| < 1.5W 时该档结论必须带
"阈值噪声带内"限定。**冲突规则：层 2 管辖层 1**——初筛方向与三种子
终判不一致时，以终判为准，并在执行记录中注明不一致事实本身。

- 单种子噪声声明：B4 种子间极差 7.4W（15.4~22.8）；层 1 的任何结论措辞
  都带"单种子 s17"限定。
- x 无论落在何处都**不得**据 B4R 结果修改 B4/B5 已判负记录（那些按各自
  预注册门槛定案）；B4R 只回答归因问题。
