# B1/B2 核心对照 pilot 数据准备报告

## 当前完成了什么

已经完成第一组严格配对的训练增强数据：

- B1：完整真实周期原样复制后重新放置；
- B2：保留同一模板周期的状态路径和时长，从其他训练周期抽取同类状态并拼接；
- 随机种子：17；
- 合成比例：真实训练周期数量的 0.5 倍；
- 每组事件数：246；
- 每组总持续时间：1,297,290 秒。

## 公平性检查

| 检查项 | 结果 |
|---|---|
| B1/B2 模板周期相同 | 通过 |
| B1/B2 周期数量相同 | 通过 |
| 每一对周期时长相同 | 通过 |
| B1/B2 放置开始时间相同 | 通过 |
| 原始家庭背景相同 | 通过 |
| 原始真实洗衣机数据相同 | 通过 |
| 合成事件相互重叠 | 0 |
| 放置区原洗衣机最大功率 | 1 W |
| 每个事件前后保护时间 | 300 秒 |
| B2 donor 来自其他 train cycle | 100% |
| validation/test 数据参与 | 0 |

简单解释：B1 和 B2 目前只有“合成洗衣机波形的构造方式”不同，其余主要条件
都相同，可以用于后续公平训练 NILM。

## 周期质量初步比较

| 指标 | B1 | B2 |
|---|---:|---:|
| 总能耗 | 181,510 Wh | 176,409 Wh |
| 相对 B1 能耗 | 100% | 97.2% |
| 平均状态边界跳变 | 889 W | 976 W |
| 平均最大边界跳变 | 1,394 W | 1,459 W |

B2 能耗与 B1 接近，没有出现整体能量失控。但 B2 的平均边界跳变约高 9.8%，说明
“直接拼接同类状态”仍会产生额外边界不连续。这不是程序错误，而是下一阶段需要
验证和优化的核心问题：

- 如果 B2 即使有稍大边界跳变，仍能提高真实 NILM 测试效果，说明状态重组提供了
  有价值的变化；
- 如果 B2 效果变差，需要测试边界平滑、边界兼容 donor 选择或保留真实 transition；
- 不能在看到最终测试结果后才决定是否启用这些约束，应先在 validation 上选择。

## 数据位置

周期级配对数据位于当前目录：

- `paired_cycle_plan.csv`：B1/B2 共用的模板周期；
- `b2_donor_provenance.csv`：B2 每个状态来自哪个训练周期；
- `paired_cycle_metrics.csv`：周期能耗和边界跳变；
- `B1/cycles/`、`B2/cycles/`：配对周期波形。

放入真实背景后的训练数据位于相邻目录 `b1_b2_placed_seed17_r0p5/`：

- `common_event_schedule.csv`：两组共用放置时间；
- `B1/shards/`、`B2/shards/`：可供 NILM 读取的增强训练时间线；
- `placement_summary.json`：放置和背景不变性检查。

## 尚不能得出的结论

当前只能说明 B1/B2 数据已经公平构建，不能说明 B2 比 B1 更好。最终需要使用相同
NILM 模型、训练轮数和随机种子，在完全真实的 validation/test 上比较 MAE、F1、
SAE 等指标。
