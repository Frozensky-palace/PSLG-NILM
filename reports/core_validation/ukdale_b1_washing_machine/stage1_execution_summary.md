# 第一阶段执行结果

> 执行日期：2026-09-20  
> 数据：UK-DALE House 1 washing machine  
> 状态：自动扫描、无泄漏划分、波形抽检、三路功率对齐和训练周期库均已完成

## 简单结论

已经从四年多的洗衣机支路数据中找出了候选完整洗衣周期，并为第一轮 B0–B5
实验划分好了训练、验证和测试数据。

第一轮只使用 2015 年 9 月更换洗衣机之前的同一台物理设备，避免把“换了设备”
造成的变化误认为某种生成方法的效果。更换后的第二台设备留作以后做跨设备测试。

## 泄漏检查

```text
passed = true
重复 cycle_id = 0
未分配 eligible cycle = 0
跨分组时间重叠 = 0
分组时间顺序正确 = true
```

简单解释：同一次洗衣过程没有同时出现在训练和测试中，测试数据目前没有被训练
数据污染。

## 第一轮波形抽检

已经从 train、validation、test 各抽取6个波形，覆盖最短、最长、典型、最低能量、
最高能量和随机周期。第一轮结果：

- 没有 NaN 或负功率；
- 最大采样缺口46秒，小于150秒容忍阈值；
- 多数周期具有清晰的加热、间歇洗涤和结束结构；
- 没有发现明显把两次完整洗衣合并成一次；
- 少数低能量、短周期可能是冷洗/快洗/漂洗/脱水，需要保留并重点分析。

当前划分可用于 pilot。正式训练前仍可扩大分层抽检数量，但不能根据模型结果
反向改变测试集。

## 三路功率对齐

所有时间点统一到 6 秒网格，并同时保存家庭总功率、洗衣机功率、原始背景功率
和截零背景功率。正式数据位于 `aligned_partitions_v2/`。

| 分区 | 时间线有效点比例 | 完整周期 |
|---|---:|---:|
| train | 97.90% | 493/493 |
| validation | 99.98% | 164/164 |
| test | 96.72% | 165/166 |

测试集中一个周期只有 44.41% 的总表覆盖，已在任何模型运行前按统一规则标为
`analysis_eligible=false`。它仍留在审计文件中，但不参与最终指标。

## B2 约束匹配诊断更新

本机已完成固定 CPU 轻量基线，只用于检查管线和优化方向，不代替服务器上的正式
Seq2Point。原始随机 B2 的 MAE/F1 为31.909 W/0.370，明显弱于 B1 的
21.277 W/0.553。

进一步检查发现原始 B2 存在大量极端时间缩放。新增的独立诊断组
`B2-matched` 用持续时间和功率特征匹配 donor，并保持模板、放置位置、训练样本、
validation 窗口完全相同。匹配后 MAE/F1 改善到23.949 W/0.484，说明 donor
约束有效，但还没有超过 B1。详细结果见 `b2_constraint_diagnostic.md`；本轮没有
访问 test 指标。
