## 3. 结论（test 终审五条）

1. **B3-D 显著优于同预算真实重组；类级结论证据不足**：半量预算（r0.5）
   下，B3-D 3/3 种子优于 B2@r0.5（Δ=−3.46W，CI 不含 0，100k 重采样 0 次
   反向）。三个生成臂方向一致（均值均更低），但仅 B3-D 达到 CI 不含 0：
   B3-T CI 含 0（[−6.70, +0.44]，2/3 种子）不称显著，B3-G 均值优 2.6W
   但被 s73 发散种子（15.70）拖到不显著。
2. **生成臂与 B2@r2.0 未检测到显著差异——等价性无法确认**：三条生成臂
   对 B2@r2.0 的 CI 均含 0（2/3 种子占优），与 validation 结论方向一致。
   注意 n=3 下 CI 宽达 ±2~4W，这只是缺乏差异证据，不构成"追平"的等价性
   证明。
3. **生成器选择在当前分辨力下不可区分**：WGAN/扩散/变换两两 CI 均含 0
   （点估计差 <0.9W）。在 n=3 分辨力下，尚不能声称"增强收益不依赖特定
   生成器"为已证结论，只能说未检测到生成器间差异。
4. **泛化衰减排序（描述性，受混杂影响）**：test−val 衰减全排序为
   B0(+0.15) < B3-D(+0.41) < B3-T(+0.54) < B1(+0.71) < B3-G(+1.40) <
   B2@r2.0(+1.45) < B2@r0.5(+2.43)。如实指出：衰减最小的是未增强基线
   B0；"合成增强更稳"仅相对 B2@r0.5 成立；且该列混合了 20k 子集与全量
   分布两种效应（见 §5），不做因果解读。另 B1@r1.0 vs B2@r2.0
   Δ=−0.98W（CI 不含 0，3/3 种子）——但效应量不足 1W（≈8%），实际意义
   待商榷，且属未校正的 10 条对比之一；只能说点估计上 B1 略优。
5. **F1/SAE 仅描述性**：B3-G F1 均值 0.777 为七组最高（vs B2@r2.0 的
   0.752，差距 0.025 在种子间波动 ±0.03~0.04 量级内）；B3-D SAE 均值
   0.183 最低但由 s42（0.089）主导——s73 反而高于 B2@r2.0（0.320 vs
   0.237），种子间异质性大。两者均无显著性检验支撑（bootstrap 只做了
   MAE），不作显著性声明。

## 4. 对立项问题的最终回答

**"基元状态生成 + 受约束组合"能否击败"直接整段生成"用于 NILM 增强？**

- **不能。E 路线（B4 基元生成）与 F 路线（B5 HSMM/端点/功率补偿）已在
  validation 阶段按预注册门槛判负**（B4 19.43±3.74；B5 系天花板在基元
  模糊性，见进展报告 §8.4），未进入 test。
- **直接整段生成（D 路线）成立**：同预算显著优于真实基线（B3-D 定案），
  追平双量真实平台，F1/SAE 占优，且在 test 分布偏移下衰减更小。
- 机制层面（推测）：瓶颈不在组合方式（B5-PC 接缝修复仅追平 B4），而在
  基元表示本身——整段生成绕开了这一瓶颈，这就是 D 与 E/F 的分界线。
  此为基于 E/F validation 判负与 D 路线对比的假说，非 test 可检验的
  结论；E/F 未进 test（预注册排除），其"判负"依据是 validation 值。

## 5. 局限（如实声明）

- **单电器、单房屋**：全部结论仅基于 UK-DALE House 1 洗衣机一个目标，
  对"NILM 增强"层面或其它电器/房屋的推广无任何证据——§4 最终回答的
  适用范围以此为边界；
- n=3 种子，配对 bootstrap 仅有 10 种重采样组合、p 值离散（~1/27 格点），
  10 条对比**未做多重比较校正**，除 B3-D vs B2@r0.5（3/3 种子 + CI 不含 0）
  外均按描述性证据对待；
- F1/SAE **无显著性检验**（bootstrap 只对 MAE），相关排序为描述性；
- validation 参考值为 20k 监控窗口子集，test 为全量——第 1 节"衰减"列
  混合了子集与分布两种效应，方向性结论（同预算排序）不受影响；
- B3-G s73（15.70）与 B0 s17（18.59）为高方差种子，test 未重跑、未剔除
  （冻结协议禁止），已如实计入全部统计。
