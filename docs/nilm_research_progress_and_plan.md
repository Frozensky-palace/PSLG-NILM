# NILM 生成式数据研究当前进度与后续规划

## 1. 当前工作状态

### 1.1 研究主线

当前论文方向确定为从 NILM 任务出发，围绕电器级用电数据的生成问题展开。核心路线是：

```text
原始 NILM 数据
-> 提取电器工作段
-> 切分电器基原状态
-> 对基原状态进行聚类
-> 针对不同基原状态建模生成
-> 按真实用电逻辑拼接生成完整工作序列
-> 评估生成数据质量与下游 NILM 任务效果
```

该路线以 PSLG-NILM 中已有的 primitive state segmentation and clustering 流程为基础，在其后增加生成、拼接、评估和系统化数据管理模块。

### 1.2 已有代码基础

本地已经有 PSLG-NILM 代码仓库：

```text
PLSG-NILM/PSLG-NILM/
```

该仓库当前已经具备以下能力：

1. 从单个电器长时间序列中提取工作段。
2. 对工作段内部进行时间序列切分。
3. 将切分后的片段张量化。
4. 使用 DETSEC、LSTM-AE、BiLSTM-AE、AutoEncoder、DTW 等方法提取表征。
5. 对片段表征进行 KMeans、DBSCAN、HDBSCAN 聚类。
6. 输出不同 cluster 对应的 `Cluster_<id>.npy`，可作为后续“基原状态生成”的训练数据。

目前 PSLG-NILM 可以作为论文中的“基原状态发现模块”，但还没有真正的数据生成器，也没有完整的多数据集统一加载层。

### 1.3 已有数据基础

目前已经下载或准备的数据集包括：

- UK-DALE
- REDD / REFIT（需确认当前所说 `reddif` 具体指 REDD、REFIT，还是两者都包含）
- ECO

当前实验建议先从 UK-DALE 入手，优先选择 kettle 作为第一个电器，因为 kettle 的工作状态功率高、事件清晰，适合验证整个流程。

### 1.4 自采集系统状态

目前自采集系统已经通过飞线方式完成，可以产生自有用电数据。后期计划将采集系统改为 PCB 板形式，提高硬件稳定性、可复现性和后续论文/系统展示的完整度。

自采集数据在论文中的作用可以分为两个阶段：

1. 第一阶段：作为外部数据源，验证系统能否接入自定义数据集。
2. 第二阶段：作为与公开数据集不同地区、不同采集方式的数据源，用于比较基原状态分布差异和条件生成效果。

## 2. 近期总目标

当前时间节点是 8 月，目标是在 11 月前形成可投递论文。因此后续工作需要控制范围，优先完成一条完整且可写成论文的闭环。

总目标：

```text
基于 PSLG-NILM 的 NILM 电器基原状态级生成方法
```

论文主贡献可以表述为：

1. 基于工作段提取、时间序列切分和聚类，构建电器基原状态数据池。
2. 提出基原状态级 NILM 数据生成方法，而不是直接生成长时间序列。
3. 基于真实状态转移和持续时间分布，将生成出的基原状态拼接为完整工作序列。
4. 从片段级、状态级、事件级和下游 NILM 任务四个层面评估生成质量。
5. 支持公开数据集与自采集数据集的统一接入，为后续系统化平台奠定基础。
